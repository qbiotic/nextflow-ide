# Privacy and Telemetry Defaults

The MVP beta has telemetry disabled by default.

- No pipeline contents, parameters, logs, artifact contents, or filesystem paths are collected.
- Run history remains in VS Code workspace state on the user's machine.
- Any future opt-in telemetry must collect only aggregate feature events, be explicitly disclosed, and respect VS Code telemetry settings.
- Runtime failures are shown locally through the extension output and notifications.
